# 📖 READ ME FIRST (دليل التشغيل السريع)

> **WebEtu Automated Meal Reservation Tool**  
> أداة حجز وجبات الإطعام الجامعي التلقائي عبر تطبيق WebEtu (البروغرس والديوان الوطني للخدمات الجامعية ONOU).

---

## 🎯 What Does This Do? (ماذا تفعل هذه الأداة؟)

* **حجز تلقائي للغداء والعشاء**: تقوم بحجز وجبتي الغداء والعشاء تلقائياً لـ **3 أيام قادمة** (نافذة متحركة 3 أيام للأمام).
* **حل مشكلة إقامة علي منجلي 04**: تم ضبط الأداة افتراضياً على **الإقامة الجامعية علي منجلي 04** (`Depot ID: 312`) والتي لا تظهر في القائمة العادية للتطبيق.
* **حماية الرصيد وتفادي التكرار**: تتأكد الأداة أولاً من الوجبات المحجوزة مسبقاً، وإذا كنت قد حجزت بالفعل لأحد الأيام تتخطاه فوراً دون أي حسم أو استهلاك إضافي.
* **أمان تام**: بياناتك (رقم التسجيل وكلمة السر) تبقى محفوظة على جهازك الشخصي فقط داخل ملف `config.json`.

---

## 🚀 Quick Start (طريقة التشغيل في 3 خطوات)

### 💻 Method 1: On Windows (على أجهزة ويندوز)

1. **تثبيت بايثون (Install Python)**:
   * إذا لم يكن بايثون مثبتاً على جهازك، حمّله من [python.org/downloads](https://www.python.org/downloads/).
   * ⚠️ **مهم جداً**: أثناء التثبيت، ضع علامة صح `[✓]` على الخيار:  
     **`Add python.exe to PATH`**.

2. **التشغيل (Run)**:
   * انقر نقراً مزدوجاً (Double Click) على الملف: **`run.bat`**.
   * في أول تشغيل، سيطلب منك البرنامج إدخال:
     - رقم التسجيل في البكالوريا (BAC Matricule)
     - كلمة سر حساب البروغرس (PROGRES Password)
     - رقم المطعم (اضغط Enter للاعتماد على المطعم الافتراضي: **علي منجلي 04**).
   * سيتم حفظ بياناتك تلقائياً وبدء الحجز فوراً!

3. **التشغيل اليومي التلقائي (Daily Automation)**:
   * لجعل الويندوز يقوم بالحجز تلقائياً كل يوم على الساعة **20:00 مساءً**:
   * انقر بزر الفأرة الأيمن على **`schedule_windows.bat`** واختر **"Run as Administrator"** (تشغيل كمسؤول).
   * انتهى! سيقوم الويندوز بتشغيل الحجز يومياً في الخلفية.

---

### 📱 Method 2: On Android Phone via Termux (على الهاتف مباشرة 24/7)

إذا كنت تفضل تشغيل الأداة على هاتفك بدون الحاجة لجهاز كمبيوتر:

1. حمّل تطبيق **[Termux](https://f-droid.org/packages/com.termux/)** من متجر F-Droid.
2. افتح Termux وانسخ الأوامر التالية والصقها:
   ```bash
   pkg update && pkg install git python cronie -y
   git clone https://github.com/fuih/webetu-bot.git
   cd webetu-bot
   bash run.sh
   ```
3. عند التشغيل لأول مرة، أدخل رقم التسجيل وكلمة السر عندما يُطلب منك.
4. لجعل الهاتف يحجز يومياً تلقائياً على الساعة 20:00:
   ```bash
   crontab -e
   ```
   أضف السطر التالي:
   ```text
   0 20 * * * cd ~/webetu-bot && bash run.sh >> reservation.log 2>&1
   ```

---

### 🐧 Method 3: On Linux / macOS (لينكس وماك)

1. افتح الطرفية (Terminal) داخل المجلد وشغل:
   ```bash
   chmod +x run.sh
   ./run.sh
   ```
2. أدخل بياناتك عند أول تشغيل.

## 🏢 Changing Your Dining Hall (تغيير الإقامة / المطعم)

إذا كنت ترغب بالحجز في إقامة أو مطعم جامعي آخر غير علي منجلي 04:

1. افتح ملف **`config.json`** في أي محرر نصوص.
2. عدّل قيمة `"default_depot_id"` برقم المطعم المطلوب:

| Depot ID | Restaurant / Residence Name | الإقامة / المطعم الجامعي |
| :---: | :--- | :--- |
| **`312`** | **RU ALI MENDJLI 04** *(الافتراضي)* | **الإقامة الجامعية علي منجلي 04** |
| `309` | RU ALI MENDJLI 01 | الإقامة الجامعية علي منجلي 01 |
| `310` | RU ALI MENDJLI 02 | الإقامة الجامعية علي منجلي 02 |
| `311` | RU ALI SAFARI | الإقامة الجامعية علي سفاري |
| `314` | RU ALI MENDJLI 05 (1000 lits) | الإقامة الجامعية علي منجلي 05 |
| `308` | RU LALA FATIMA N SOUMER | الإقامة الجامعية لالة فاطمة نسومر |
| `527` | MENTOURI CAMPUS | المجمع الجامعي الإخوة منتوري |
| `526` | ZARZARA CAMPUS | المجمع الجامعي زرزارة |

> 💡 لمعرفة أرقام المطاعم الأخرى في ولايتك، شغّل الأمر:  
> `python webetu_client.py restaurants`

## ⚙️ Advanced Settings (إعدادات إضافية)

ملف **`config.json`** النموذجي:
```json
{
  "username": "YOUR_BAC_MATRICULE",
  "password": "YOUR_PASSWORD",
  "default_depot_id": 312,
  "default_meals": [2, 3]
}
```

* `"default_meals"`:
  * `[2, 3]`: غداء وعشاء فقط (Lunch & Dinner) - *الافتراضي والموصى به*.
  * `[1, 2, 3]`: فطور وغداء وعشاء (Breakfast, Lunch & Dinner).

## ⚠️ Important Rules (ملاحظات وتنبيهات هامة)

1. **قانون الـ 24 ساعة**: نظام WebEtu لا يسمح بحجز وجبة نفس اليوم. يجب أن يكون الحجز قبل 24 ساعة على الأقل، ولهذا تقوم الأداة بحجز 3 أيام قادمة مسبقاً.
2. **الاتصال بالإنترنت**: خوادم وزارة التعليم العالي (`progres.mesrs.dz`) تحجب عناوين الـ IP الأجنبية خارج الجزائر. لذلك يجب تشغيل الأداة عبر اتصال إنترنت جزائري (Wi-Fi محلي أو بيانات 4G Mobilis / Djezzy / Ooredoo)، وبدون تشغيل برامج VPN أجنبية.
3. **سرية الحساب**: لا تشارك ملف `config.json` مع أي شخص لأنه يحتوي على كلمة سر حسابك.
